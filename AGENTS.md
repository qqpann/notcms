# Agent guidance

This is the public `notcms` SDK repository. The private NotCMSApp repository's
Japanese-language policy does not apply here, including when this repository is
checked out as its submodule.

## Language

- Use English for code comments, JSDoc, documentation, PR titles, and PR descriptions by default.
- Add English/Japanese bilingual content only when explicitly requested. Keep facts, API examples, validation results, and checklist states aligned between both languages.
- Preserve existing translated files, such as `README.ja.md` and `docs/ja/`, and other explicitly multilingual deliverables in their intended language. The English default does not authorize deleting or converting them.
- Follow the [PR template](.github/PULL_REQUEST_TEMPLATE.md). A Japanese section is needed only when explicitly requested.
